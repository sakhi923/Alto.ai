Pertanyaan yang Sering Diajukan

Anda dapat menggunakan fitur integrasi bawaan Kodein: klik tombol "Push ke GitHub" di header ruang kerja, masukkan pesan commit, dan kode akan langsung terkirim. Anda juga dapat menggunakan menu Settings > Export to GitHub di pojok kanan atas untuk mengekspor seluruh kode ke repo baru Anda secara instan.
Sangat mudah! Anda dapat mengklik tombol "Publikasikan Link" di header Kodein untuk menyalin tautan web publik aktif, atau memanfaatkan menu Share di panel atas Google AI Studio untuk membagikan link pratinjau yang langsung bisa dibuka siapa saja.
Tidak sama sekali! Seluruh runtime, server sandbox, dan editor kode Kodein berjalan 100% di browser dan cloud, sehingga Anda bisa langsung mulai tanpa konfigurasi lokal yang rumit.
